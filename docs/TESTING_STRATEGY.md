# Testing Strategy

The repository does not currently contain a complete automated test suite.

## Recommended Coverage

- Mobile component, navigation, API-client, device, upload retry, and playback tests
- FastAPI service, route, schema, JWT, authorization, and database integration tests
- Worker frame-extraction, detector-adapter, rules-engine, retry, failure, and idempotency tests
- End-to-end upload, processing, moderation, feed visibility, and manual-review tests
- CI linting, type checking, dependency scanning, container scanning, migration checks, load testing, and rollback validation
