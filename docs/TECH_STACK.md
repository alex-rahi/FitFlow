# Technology Stack

| Layer | Technology | Role |
|---|---|---|
| Mobile | React Native, Expo, TypeScript | Cross-platform UX |
| Routing | Expo Router | File-based navigation |
| Backend | FastAPI, Python | REST APIs and business logic |
| Validation | Pydantic | Request/response schemas |
| Database | PostgreSQL / Supabase | Relational data |
| Authentication | Supabase Auth, JWT | Identity and authorization |
| Storage | Supabase Storage | Videos and thumbnails |
| Worker | Python, OpenCV, NumPy, Pillow | Media processing |
| Detection | Ultralytics YOLO | Object detection |
| Rules | YAML + Python | Policy outcomes |
| Admin | Next.js, React, TypeScript | Moderation operations |
| Local deployment | Docker Compose | Multi-service development |
| Production topology | Kubernetes and Ingress | Container orchestration |
| Delivery | CDN configuration | Edge media delivery |
