# Roadmap

## Complete Integration

Connect a real Supabase development project, validate authentication, complete direct upload, persist processing state, connect live admin data, and add automated tests.

## Validate Safety

Define evaluation data, measure false positives and false negatives, version models and thresholds, calibrate confidence, and implement human-review procedures.

## Production Hardening

Add CI/CD, scanning, managed secrets, queue-backed workers, telemetry, backups, recovery, load testing, autoscaling, and CDN delivery.

## Product Growth

Add personalized ranking, watch-time metadata, creator analytics, improved discovery, delivery notifications, trust signals, and accessibility improvements.
