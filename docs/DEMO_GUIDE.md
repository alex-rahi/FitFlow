# Interview Demo Guide

## Seven-Minute Flow

1. **Product:** Describe GymTok as a social fitness MVP with AI-assisted moderation.
2. **Screens:** Show the welcome screen, local feed, and moderation dashboard.
3. **Mobile:** Open the feed, upload, and authentication context files.
4. **Backend:** Show `main.py`, one router, one service, schemas, JWT, and middleware.
5. **Worker:** Show `processor.py` and `rules/config.yaml`.
6. **Admin:** Show the dashboard, review queue, and audit pages.
7. **Production:** Show Docker Compose, Kubernetes, database migrations, and architecture.
8. **Close:** Explain the boundary between implemented MVP behavior and production next steps.

## Suggested Introduction

“GymTok is a cross-platform social fitness MVP. I designed the mobile experience, API, database, AI-processing workflow, moderation dashboard, and production deployment path as one system.”

## Fallback

Keep the screenshots and `docs/GymTok_Demo.pdf` open. If a live service fails, continue with the source and architecture walkthrough.
